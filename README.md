# OptPdfEditor

ブラウザだけで完結する PDF ツール（PDF 結合 / ページ編集 / zip→PDF 変換）。インストール不要の静的な Web ページで、選んだファイルはサーバーへ送信せず、ブラウザの中で処理します。個人開発の「Opt アプリ」シリーズの 1 つです。

- 状態: 開発中。作者の Web サイトで公開予定
- 技術構成: HTML + JavaScript（ビルド不要）。pdf-lib（PDF の生成・編集）、PDF.js（プレビュー）、JSZip（zip の展開）、fontkit + harfbuzz（日本語フォントのサブセット埋め込み）

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | ホーム（各ツールへのリンク） |
| `pdf-merge.html` | PDF 結合。PDF・画像（JPG / PNG / WebP）・テキストを並べ替えて 1 本の PDF にまとめる |
| `pdf-edit.html` | ページ編集。削除・回転・並べ替え・抽出・分割、別の PDF の差し込み・差し替え |
| `zip2pdf.html` | zip→PDF 変換。画像とテキストを収めた zip を PDF にする（テキストはフォント埋め込みで検索・コピー可） |
| `lib/opt-topdf.js` | 画像・テキストを PDF のページにする共通処理 |
| `lib/` | 同梱ライブラリとフォント（[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)） |

## 使い方

Web サーバーで配信して `index.html` を開きます。手元で試すときは、このフォルダで次を実行してブラウザで `http://localhost:8000/` を開きます。

```
python -m http.server 8000
```

`index.html` をダブルクリック（`file://`）でも動きますが、次の制限があります。

- フォントが埋め込まれていない日本語の PDF は、プレビューで文字が表示されないことがあります（CMap を読み込めないため）
- 日本語フォントと harfbuzz は、少し重い base64 版を読み込みます

## プライバシー

ツールで選んだファイルは、ブラウザの外に送信されません。通信が発生するのは、ページ本体と `lib/` のライブラリ・フォントを読み込むときだけです。
